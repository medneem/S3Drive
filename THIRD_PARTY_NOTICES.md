# Сторонние компоненты

- **PySide6 / Qt** — LGPL/GPL или коммерческие условия по выбору лицензии; при распространении исполняйте условия лицензий Qt.
- **PyInstaller** — GPL с исключением для использования сборочного загрузчика.
- **Pillow** — HPND.
- **pywin32** — PSF-style license.
- **rclone v1.75.2** — MIT (Copyright Nick Craig-Wood); `rclone.exe` включён в ZIP, текст лицензии: `RCLONE_LICENSE.txt`.
- **WinFsp 2026 Beta4 (v2.2B4)** — GPLv3 с исключением для открытого ПО; официальный MSI включён в ZIP, но требует установки с правами администратора. [Исходный код и условия лицензии](https://github.com/winfsp/winfsp).

GitHub Actions загружает официальные релизы и проверяет SHA256 перед упаковкой. WinFsp не распаковывается как драйвер в рабочую директорию: в ZIP присутствует только официальный MSI, который устанавливается по явному действию пользователя.
